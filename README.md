# Laboratorio 1 · Catálogo de libros

Programación Avanzada y Entornos de Desarrollo para la IA · Tema 1

Obtén los datos de una tienda de libros ficticia (https://books.toscrape.com), prepáralos, explóralos y muéstralos en una app interactiva.

Tienes libertad para elegir las librerías, los campos que extraes y cómo presentas los datos. Explica en el notebook qué has usado y por qué.

## Qué vas a practicar

| Paso | Contenido | Día |
|---|---|---|
| Entorno y dependencias | `venv` o `uv`, `requirements.txt` | 3 |
| Scraping | por ejemplo `requests` y `BeautifulSoup` | 2 |
| Procesamiento y análisis | por ejemplo pandas o Polars, y una librería de gráficos | 1 y 2 |
| App interactiva | Streamlit, Gradio, Dash, Panel... | 2 |
| Git y GitHub | repositorio, commits claros y README | 3 |
| Uso de IA | reflexión sobre el asistente de programación | 3 |

El procesamiento de datos se hace de forma básica; lo veremos en detalle en el Tema 2.
